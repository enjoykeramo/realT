# realT 算法设计

## 0. 目标与口径

- **只做有底仓的个股**。做T = 当天一买一卖等量股票,收盘后持仓数量不变。
  - 先卖后买:先卖底仓,低位买回
  - 先买后卖:先低吸,高位卖出等量**底仓**(满足 T+1)
- **一次T算赢**:`(卖价 − 买价) × 股数 − 佣金 − 印花税 − 过户费 > 0`。
  收盘前 6 分钟仍未平仓的,按市价强制恢复底仓,计入盈亏(不允许"拿着等明天")。
- **达标** = 出手胜率 ≥ 80% **且** 净盈亏 > 0。只看胜率没有意义(止盈很小、止损很大也能 80%)。
- **接受不出手**。达到高胜率的代价是只在看得清的日子出手,出手日占比会明显低于原型。
- 回测成交:市价单在信号后**下一根** 1 分钟线开盘价成交,单边滑点 2bp;挂单须价格穿过挂单价才成交;止盈为限价单。默认佣金万 1(最低 5 元)、印花税万 5(卖)、过户费十万分之一,可用 `realt config` 修改。

## 1. 分层架构

```
开盘前  L1 大盘环境 ──┐
        L2 主力阶段 ──┼──> L3 分时形态先验
        集合竞价缺口 ──┘          │
盘中每分钟                        ▼
        今日分时走势 ──────> L3 形态后验(贝叶斯式更新)
        1 分钟/5 分钟 K 线 ──> L4 信号(缠论/布林/均价/RSI + 5 分钟确认)
                                   │
                                   ▼
                          L5 决策与风控状态机 ──> 高抛/低吸/回补/卖出 建议
                                   │                 ▲
                                   ▼                 │ 门控
                          L6 迷宫记忆(按上下文统计胜率)
```

| 层 | 代码 | 要点 |
|---|---|---|
| L1 大盘环境 | `core/regime` | 指数相对 MA20/MA60、MA20 斜率、20 日动量、60 日区间位置、市场宽度(上涨家数占比、涨停−跌停)。输出 主升/偏强/震荡/偏弱/主跌 五档及 −1..1 分数 |
| L2 主力阶段 | `core/stage` | 120 日区间位置、20/60 日涨幅、距 20 日高点回撤、量比、布林带宽分位、均线排列、OBV 背离、上影线。规则打分后 softmax 得到 建仓/拉升/洗盘/主升/派发/下跌 的**概率** |
| L3 分时形态 | `core/daytype` | 六类:单边上涨、单边下跌、冲高回落、探底回升、宽幅震荡、窄幅横盘。先验 = 基础比例 × 方向偏置(L1、L2)× 开盘缺口;盘中特征按已过时间 √t 归一化后更新后验 |
| L4 信号 | `core/chan`, `core/signal` | 结构:缠论(包含→分型→笔→中枢→背驰→一二三类买卖点)、布林上下轨刺破收回、RSI 极值拐头;位置:偏离均价线的 ATR 倍数;确认:5 分钟 MACD 柱连续变化、5 分钟 %b 从极值回落(区间套) |
| L5 决策风控 | `core/engine/TEngine` | 方向门控(偏多概率高禁先卖,偏空概率高禁先买)、动量过滤、空间覆盖成本检查、止盈/回归均价/反向信号/保本/止损/尾盘收尾 |
| L6 迷宫记忆 | `core/learn/ContextMemory` | 路口 = 大盘档位 × 主力阶段 × 入场时形态 × 方向 × 信号家族。样本不足时允许试错;Beta 后验胜率低于目标视为死路,不再出手 |

## 2. "迷宫"类比如何落地

把每个交易日看成一座迷宫:终点(收盘方向)未知,只能根据局部观察一步步走。

1. **地图的先验**:L1/L2 + 缺口,给出今天大概是哪种迷宫(L3 先验)。
2. **边走边修正**:每根 K 线更新 L3 后验 —— 这是部分可观测马尔可夫决策过程(POMDP)里的"信念更新"。
3. **撞墙回头**:止损、保本离场、尾盘收尾是"回头"。墙要近(认错条件清晰),回头要便宜(只动 T 仓、每日次数有限)。
4. **在路口做标记**(Trémaux 算法):L6 记录每个路口走过的结果,样本足够后,胜率不达标的路口不再进入。
5. **两个层面的试错**:
   - 路口层面:L6 在线学习,按时间顺序更新,只用已结束交易日的结果(含未出手的"影子交易",实盘同样可以记录),不使用未来数据。
   - 参数层面:`realt sweep` 在训练区间尝试多组参数,在之后的测试区间做样本外检验。
6. 试错发生在**历史回放**里,而不是用真金白银。

## 3. 训练(`realt train`)与参数包

规则打分无法在真实数据上达到目标(见第 4 节),因此"什么时候该出手"交给从历史数据学出来的模型,
规则只负责产生候选点和执行离场(元标签 / meta-labeling)。

### 3.1 候选点与特征

- **候选点**:任一方向出现转折结构 —— 缠论 1 分钟一/二/三类买卖点、缠论 5 分钟买卖点(区间套)、布林刺破后收回、RSI 极值拐头;
  开盘 5 分钟后、收盘 20 分钟前。训练与实盘同一定义(`Features.candidates`)。
- **指标增量计算**(`signal/Timeframe`、`signal/SignalEngine`):1/5/15 分钟 K 线的 MACD、布林、RSI 每分钟 O(1) 更新,
  与批量算法逐值一致(单元测试保证);缠论每分钟对 1 分钟与 5 分钟各做一次结构识别。
- **特征按层/模块分组**(`ml/Features`,约 110 个),每组都是该模块的**连续状态**而不只是"是否出信号":

| 组 | 主要内容 |
|---|---|
| 缠论 | 买卖点类型;本方向段与前一同向笔的 MACD 面积比(背驰程度)、是否创新高/新低;反方向段面积比;自最后分型的位移与 K 线数;价格在最后中枢中的位置;5 分钟级别的面积比、买卖点强度、位移 |
| MACD | 1/5/15 分钟 DIF、DEA、柱值、柱斜率(ATR 归一),1 分钟最近金叉/死叉 |
| 布林%b | 1/5/15 分钟 %b,1/5 分钟带宽,近 5 分钟 %b 极值 |
| 均价线/RSI | 均价线偏离(ATR)、1/5 分钟 RSI、30 分钟位移 |
| L3 分时形态 | 六类形态后验概率、顺势程度 |
| 分时状态 | 已过时间、距开盘涨跌、振幅、日内位置、距高低点、均价线斜率、量比、资金流向近似、短期波动、ATR |
| 指数分时 | 同一分钟指数涨跌、相对其均价线、30 分钟斜率、个股相对强弱 |
| L1 大盘 | 大盘环境分 |
| L2 主力阶段/日线 | 阶段概率、120 日位置、涨幅、回撤、量比、带宽分位、均线排列、昨日结构、距均线 |
| 涨跌停距离 | 逆向/同向涨跌停价距离 |

### 3.2 订单与离场(训练与实盘同一引擎、同一撮合规则 `SimBroker`)

- 开仓:市价(下一根开盘价+滑点)或**挂单**(先卖挂在现价上方 0.1 ATR、先买挂在下方,5 分钟内有效,
  价格须穿过挂单价 1 个价位才算成交)
- 止盈:**限价单**,K 线触及即按止盈价成交
- 回归均价、反向信号、保本、尾盘锁利(收盘前 30 分钟扣费后有盈利即完成)、止损、14:54 后强制恢复底仓
- 成本按实际 T 仓规模计算(含最低 5 元佣金)

### 3.3 训练流程:迭代寻优

1. **候选生成与打标签**:每个候选点 × 32 组「开仓方式(市价/挂单0.1ATR)× 止盈(0.08/0.12/0.18/0.25 ATR)× 止损(0.6/1.0/1.6/2.5 ATR)」
   各模拟一次,扣全部费用后盈利为赢;同时记录信号来源、方向、时间、大盘档位、ATR、均价偏离、顺势程度等策略维度
2. **时间切分**:模型训练期(前 40%)| 寻优期(40%~70%)| 二次验证期(70%~85%)| 最终验收期(最后 15%)
3. **胜率模型**:两个 GBDT(A:市价/止盈0.12/止损1.0 的输赢;B:市价/止盈0.25/止损1.6),滚动前推,
   每段只用之前的数据训练并做概率校准。"大盘环境"是同一天所有股票相同的变量,几十天样本下放进模型容易记住"哪天好",
   因此不进模型,改为策略的过滤条件,由验证期检验
4. **模块消融**(可选):在寻优期衡量各层/模块对模型的贡献
5. **迭代寻优**(遗传算法):第 1 代 = 32 条"全开"策略 + 随机策略;每轮在寻优期回测打分
   (适应度 = 胜率 Wilson 95% 下限,要求净盈亏 > 0、笔数 ≥ 30),保留前 10% 精英,变异(改 1~3 个维度)+ 交叉 + 随机新个体组成下一代;
   每轮前 10 名做二次验证(验证期胜率 ≥ 目标、净盈亏 > 0、笔数 ≥ 30 为通过);
   已有策略通过验证且连续 12 轮没有更好的验证结果时停止,最多 60 轮
6. **最终验收**:验证表现最好的策略在验收期回测一次,报告是否达标;参数包写入该策略

回测引擎 `TEngine` 用参数包中的同一份 `StrategySpec` 决定出手,单元测试保证训练器在验收期的结果与引擎逐分钟回放一致。

### 高胜率的代价(必须理解)

胜率 95% 时,每 20 笔只能亏 1 笔。若平均盈利 W、平均亏损 L,不亏钱要求 `0.95·W > 0.05·L`,即 L < 19W。
止盈小、止损宽能提高胜率,但亏损单会很大;所以训练同时要求净盈亏 > 0,不能只追胜率。
在模型无法区分的情况下,唯一能提高胜率的办法是更挑剔(阈值更高),代价是出手次数下降。

## 4. 第一次真实数据回测的结论(98 只股票,2026-06 ~ 2026-10)

规则版(未训练)在真实数据上**没有达到目标**:realT 胜率约 48%、净亏损;原型规则 51%、净亏损。
拆开看,问题集中在两处:

- **方向与当日形态是否一致决定一切**:顺势(冲高回落日先卖、探底回升日先买、单边上涨日先买)胜率 84%~91%;
  逆势胜率只有 23%~37%。而 10:30 时的形态预判准确率只有 34%,大量把单边日误判为宽幅震荡。
- **持有到尾盘被迫收尾**是最大亏损来源(560 笔,胜率 21%)。

这正是训练要解决的:模型直接学习"在当前特征下这一笔能否赢",而不是依赖准确的形态分类。

开发中用合成数据得到的几条结构性经验已体现在默认规则中:14:00 后不开新仓(规则模式)、5 分钟确认要求"转折"而非"位置"、
冲高回落后半程按下跌处理、均价线作为回归目标。合成数据上的胜率数字没有实盘意义。

### 第一次训练(100 只,87 天,候选点 41 万,目标 80%)

- 不过滤时测试段胜率 67.9% 但净亏 11 万:止盈 0.45/止损 1.2 ATR 下小赚大亏。
- 模型给出的最高胜率概率约 0.82~0.85,说明当时的特征区分度不足;阈值 0.8 时测试 71 笔、胜率 83% 但仍净亏。
- 选定阈值 0.82 后测试段只有 5 笔,"100%"没有统计意义。
- 特征重要性:时间(31%)、日线大盘分(15%)、ATR、均价偏离;L4 结构信号几乎不起作用。
  → 第二版加入指数分时、资金流向近似、涨跌停距离、昨日结构等特征,并改为滚动前推验证、报告置信区间、增加更小止盈的离场组。

### 第三次训练(300 只,87 天,候选点 127 万,目标 95%)

- 测试段 0 笔:各段模型的原始概率不可比,测试段模型的概率整体偏低,0.86 的绝对阈值在测试段没有候选能达到
  → 第四版对每段模型做概率校准,阈值改为"校准胜率"
- 最终模型只有 34 棵树,特征重要性集中在时间、大盘、指数,缠论/MACD/布林几乎不起作用(只以粗粒度综合分进入)
  → 第四版为每个模块提供连续状态特征,并用消融衡量各层贡献
- 亏损主要是"先卖后买 → 尾盘收尾" → 止盈改为限价触及即成交,增加挂单开仓选项

### 第四次训练(300 只,87 天,候选点 164 万)

- 模型 AUC 只有 0.554(0.5 为随机),不过滤胜率约 68% 且平均每笔为负;各模块消融差异都在 ±0.01 以内
- 最重要的特征是日线大盘分(19.9%):样本只有几十个交易日,模型在记"哪几天好",测试段的大盘状态不同,概率整体下移,再次 0 笔
  → 第五版改为迭代寻优:大盘环境作为策略过滤条件经验证期检验,模型只是可选过滤;训练流程即"配置→回测→保留→二次验证→迭代→一次性验收"

## 5. 已知局限与后续计划

- **价格未复权**:除权日(分钟线开盘偏离昨收超过涨跌停幅度)整日跳过;但 120 日日线特征在除权前后可能失真。后续可读取 `vipdoc\cw` 权息数据做前复权。
- **ST 股**:离线日线不含 ST 标记,涨跌停家数统计按普通涨跌幅计,略有偏差。
- **L2 主力阶段**目前是规则打分,尚未用历史数据校准;可以用"之后 N 日走势"作为标签做监督校准。
- **能否达到 80%** 取决于真实数据上 `train` 的测试集结果。若测试集达不到,报告中的「阈值—胜率」表会给出可达到的最高胜率及对应出手次数,据此决定取舍或补充数据/特征。
- **L3 先验**可由 L6 积累的"上下文 → 实际形态"统计替换(`DayTypePredictor.priorOverride` 已预留)。
- **性能**:缠论每根 K 线对前缀重算,单只股票一天约 10ms;参数扫描通过共享观察(`Observer`)避免重复计算。
- **实时接入**:`TEngine.onBar / onFill` 即为实时接口;stockAPP 负责行情推送和用户确认成交。
